Type a word. Get a pixel icon in two styles.

A skill for Claude, Cursor, Codex and other AI tools. It draws 16×16 icons in the Pixtober style, one in colour and one in black and white, and saves them as SVGs for your code or Figma.

Use it in the tool you already have

Install the skill once, then ask for any word: "make a pixel icon of a lantern". Your AI tool picks an idea, draws both styles, checks them against the style rules and saves two SVGs.

For Claude on the web, desktop and phone.

  1. Download pixel-icons.zip
  2. In Claude, open Customize → Skills, choose +, then Create skill → Upload a skill, and pick the ZIP.
  3. Turn the skill on and ask: "make a pixel icon of a lantern".

Code execution needs to be on, under Settings → Capabilities. Claude's guide to skills

Add the plugin from inside Claude Code:

/plugin marketplace add iamjahanvi/pixel-icon-generator
/plugin install pixel-icons@pixel-icon-generator

Then ask for an icon, or run /pixel-icons:pixel-icons lantern.

Works with Cursor, Codex, OpenCode, Gemini CLI and dozens of other agents that read Agent Skills. Run it in your project and pick your tools when it asks:

npx skills add iamjahanvi/pixel-icon-generator

Using GitHub Copilot? Install with the GitHub CLI:

gh skill install iamjahanvi/pixel-icon-generator pixel-icons

Copy the skill into your project with one command. It needs Node 18 or newer.

npx pixel-icon-generator init
  • --claude installs into .claude/skills/ for Claude Code
  • --cursor installs into .cursor/skills/
  • --global installs into your home folder, for every project

Without a flag it goes into .agents/skills/, which Cursor, Codex and Copilot all read.

No skills support? Copy the style rules as one prompt. It works in ChatGPT, Gemini, Claude or any other chat.

  1. Paste the prompt into your chat.
  2. Copy the whole reply.
  3. Paste it into the editor with "Paste from AI". It checks both icons and gives you the SVGs.

Two styles from two Octobers

Pixtober is Jahanvi Singh's pixel-icon series: one icon a day through October. The skill learned its rules from her 2024 and 2025 editions and draws every word in both.

Colour, from Pixtober 2024

  • A 1px pure black outline that always closes
  • The object's real colours, 2–4 plus black
  • One darker shade per material, and thin 1px highlights
  • Flat colour, no dithering

Black & white, from Pixtober 2025

  • Only pure black and white
  • A bold outer outline at least 2px thick, with 1px lines inside
  • White for the shape and light, black for shadow and dark parts
  • Checker patterns, only for texture
